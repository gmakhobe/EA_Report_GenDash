# EA_Report_GenDash
This project consist of a report Generator written in python and a Dashboard
## Report Generator
This is written in python for the purpose of transforming data retrieved from an EA Agent to information that can be view from the from Dashboard that is written in VueJS.

The reason for the existance of the generator is to help me take the information about orders and deals from the Metatrader Test Agent and organise it properly to the information that can be used by the Dashboard.
